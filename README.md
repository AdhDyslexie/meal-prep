# Meal Prep Android App Project - Assignment 3 (159.336)

Mobile Application Development course A3, where ive chosen to develop a meal prep / planning app

## Technical Requirements & Constraints

1. **Tech Stack:**
    - **Language:** Kotlin
    - **UI Framework:** Jetpack Compose (Apps using Java or traditional Views will receive 0 marks. A View may only be used if completely unavoidable for a 3rd-party library, but the vast majority of the UI must use Compose).
    - **Compose Version:** Must use the exact same version of Compose as the Greetings example app.
2. **Class Limitations:**
    - **Maximum Classes:** 10 Kotlin classes for an individual submission, or 20 classes for a group submission. Exceeding this limit without prior email exemption will result in 0 marks.
    - **Exclusions from Class Count:** Simple data classes (with no methods), theme classes, factory classes, database entities, and external library classes (included as Gradle dependencies, not copied into `src`).
3. **External Libraries & Code Reuse:**
    - External libraries are allowed via Gradle dependencies (must be documented in comments). Complete third-party frameworks (such as game engines) are prohibited.
    - You may incorporate your own existing code (e.g., from previous courses like 159.261), provided it is clearly documented in comments.
    - **Strict Academic Integrity:** Zero tolerance for plagiarism. Apps based directly on online tutorials, books, or repositories will receive 0 marks and may be reported to the academic integrity office.
4. **App Behavior & Performance:**
    - The application must be well-written, non-offensive, and behave well with other apps (e.g., properly release system resources when not in use).
    - Must be compatible with and tested on the Android emulator.
5. **Build & Configuration Integrity:**
    - The project must build successfully using the standard Gradle command line.
    - **Do not** modify anything inside the `gradle` folder (except `libs.versions.toml`) or the `gradlew` scripts.
